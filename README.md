# Jumpon Shift ICS

เว็บส่วนตัวสำหรับอัปโหลดรูปตารางเวร ค้นหาชื่อ “จุมพล” ด้วย OCR ในเบราว์เซอร์ ตรวจทานวันที่ และดาวน์โหลดไฟล์ปฏิทิน `.ics`

- รูปและรายชื่อไม่ถูกส่งไปเก็บในฐานข้อมูลของแอป
- OCR เป็นตัวช่วย ผู้ใช้ต้องตรวจวันที่กับรูปต้นฉบับก่อนดาวน์โหลด
- รองรับกิจกรรมทั้งวันหรือระบุเวลาแยกตามประเภทเวร
- แยกเวลาเริ่ม–สิ้นสุดของวันธรรมดาและวันหยุด โดยเสาร์–อาทิตย์เป็นวันหยุดอัตโนมัติและเพิ่มวันหยุดราชการเองได้
- จำชื่อที่ค้นหา ชื่อเวร เวลา สถานที่ และการแจ้งเตือนไว้ในอุปกรณ์สำหรับเดือนถัดไป โดยไม่เก็บรูปตารางเวร
- เลือกแยกเวร 1/2 จากตำแหน่งชื่อช่วงบนหรือช่วงล่างของช่องวันที่ พร้อมตรวจแก้ด้วยตนเองก่อนส่งออก
- ติดตั้งเป็น PWA บนโทรศัพท์หรือคอมพิวเตอร์ได้
- หน้าแอปและข้อมูลพื้นฐานเปิดแบบออฟไลน์ได้ หลังเปิดใช้งานออนไลน์ครั้งแรก

## GitHub Pages

Repository นี้มี GitHub Actions ที่เผยแพร่โฟลเดอร์ `dist` ไปยัง GitHub Pages อัตโนมัติเมื่อ push เข้า branch `main`

1. เปิด **Settings → Pages** ใน repository
2. ตั้ง Source เป็น **GitHub Actions**
3. เปิดแท็บ **Actions** เพื่อตรวจงาน `Deploy PWA to GitHub Pages`

> OCR ภาษาไทยใช้ Tesseract.js จาก CDN จึงควรเปิดออนไลน์ในการใช้งานครั้งแรก หลังทรัพยากรถูกแคชแล้วจึงรองรับการใช้งานออฟไลน์ได้ดีขึ้น
